# HTML Email Templates by Taha Soumbate

**Live portfolio:** https://tahasoumbate.github.io/ (home, emails, bug fixes, Figma to HTML, landing pages)

30 responsive email designs (account, newsletter, payment, e-commerce, notification, survey and report emails), each built in 5 technologies:

| Folder | What's inside |
|---|---|
| `emails/html-css/` | Hand-coded tables with inline CSS, ready to send |
| `emails/tailwind/` | Built with Tailwind CSS, compiled to inline HTML |
| `emails/maizzle/` | Built with Maizzle, compiled to inline HTML |
| `emails/mjml/` | Built with MJML, compiled to inline HTML |
| `emails/bootstrap-email/` | Built with Bootstrap Email, compiled to inline HTML |
| `source/` | The source files for Tailwind, Maizzle (`.vue`), MJML (`.mjml`) and Bootstrap Email |

Every email uses table layouts, inline styles, Outlook-safe buttons and a layout that stacks on phones.
