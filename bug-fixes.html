What I fixed, and why it broke

Every fix comes with a short note like this, so you know exactly what changed in your code.

  1. The page scrolled sideways on phones

    The page had a fixed 1100px width, wider than any phone.

    .wrap { width: 1100px; }.wrap { max-width: 1100px; padding: 0 20px; }

  2. The text was too small and too light

    11px light brown on beige is hard to read for everyone.

    .hero p { font-size: 11px; color: #c9a57a; }.hero p { font-size: 18px; color: #4a3420; }

  3. Product text spilled out of the cards

    The cards had a fixed height and floats, so long text overflowed.

    .card { float: left; width: 340px; height: 150px; }.cards { display: grid;
  grid-template-columns: repeat(auto-fit, minmax(240px, 1fr)); }

  4. The menu button did nothing

    A typo in the function name, so the click called nothing.

    onclick="toggleMneu()"onclick="toggleMenu(this)" aria-expanded="false"

  5. "Order now" could not be clicked

    The link had no href, so it was not a real link for mouse, touch or keyboard.

    <a class="btn">Order now</a><a class="btn" href="#">Order now</a>
