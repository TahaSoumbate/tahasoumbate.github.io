What I fixed, and why it broke

  • Page scrolled sideways on phones. The page had a fixed 1100px width. I changed it to a max-width with padding.
  • Text too small and too light. 11px light-brown text on beige. Now 18px with enough contrast to read.
  • Product text spilled out of the cards. Cards had a fixed height and floats. Now a CSS grid that grows with the text and stacks on phones.
  • Menu button did nothing. A typo in the JavaScript function name. Fixed, and the button now tells screen readers if the menu is open.
  • "Order now" could not be clicked. The link had no href, so it was not a real link. Now it works with mouse, touch and keyboard.
  • You always get a note. Every fix comes with a short explanation like this list, so you know what changed.
